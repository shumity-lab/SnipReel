# SnipReel

macOS のメニューバーに常駐する、範囲キャプチャ・画面録画アプリです。

- 選んだ範囲をキャプチャして、画面の最前面に貼り付けておける
- キャプチャに鉛筆で書き込める
- サイズ変更や JPEG 変換で、ファイルサイズを小さくできる
- 選んだ範囲を、システム音声・マイクの音と一緒に録画できる

## 動作環境

- macOS 15 以降(Apple シリコン / Intel)

## インストール

1. [Releases](https://github.com/shumity-lab/SnipReel/releases/latest) から `SnipReel-<バージョン>.dmg` をダウンロードして開く
2. `SnipReel.app` を「アプリケーション」フォルダにドラッグする
3. SnipReel を起動すると、メニューバーにアイコンが表示されます(Dock には表示されません)

### 初回の許可

- **画面収録**: 初めて起動したときに許可を求められます。システム設定 →「プライバシーとセキュリティ」→「画面収録とシステムオーディオ録音」で SnipReel をオンにして、SnipReel を再起動してください。
- **マイク**: 録画でマイクをオンにしたときに許可を求められます。

## キャプチャ

1. `⇧⌘2` を押す(またはメニューバーのアイコン →「範囲をキャプチャ」)
2. キャプチャしたい範囲をドラッグする(`Esc` または右クリックでキャンセル)
3. キャプチャが画面の最前面に表示され、クリップボードにもコピーされます

### キャプチャの操作

| 操作 | 内容 |
|---|---|
| ドラッグ | キャプチャを移動 |
| 四隅をドラッグ | 縦横比を保ったまま拡大・縮小 |
| `Ctrl` + 右ドラッグ | 鉛筆で書き込み |
| 右クリック | メニュー(コピー / 保存 / 取り消し / 鉛筆の色・太さ / 閉じる) |
| `⌘C` | コピー(書き込みも含む) |
| `⌘S` | 保存 |
| `⌘Z` / `⇧⌘Z` | 書き込みの取り消し / やり直し |
| `Esc` | 閉じる |

### 上部の帯

キャプチャの上に表示される帯で、次のことができます。

| 項目 | 内容 |
|---|---|
| ⓧ | 閉じる |
| `1280 × 720 px` | 保存される画像のサイズ |
| `245 KB` | 保存したときのファイルサイズの目安 |
| サイズ(`100%`) | 100 / 75 / 50 / 33 / 25% から選ぶ、または「サイズを指定…」で幅・高さを指定 |
| 形式(`PNG`) | PNG(劣化なし)/ JPEG 高画質・標準・低画質。JPEG にするとファイルサイズが小さくなります |
| コピー / 保存 | `⌘C` / `⌘S` と同じ |

サイズや形式の設定は、コピー・保存する画像に反映されます。

## 画面録画

1. `⌥⇧⌘2` を押す(またはメニューバーのアイコン →「画面を録画」)
2. 録画したい範囲をドラッグする(**クリックだけなら画面全体**、`Esc` でキャンセル)
3. 3 秒のカウントダウンのあと、録画が始まります

録画中は範囲の周りに赤い枠が、すぐ近くに操作バーが表示されます(どちらも動画には写りません)。

### 操作バー

| ボタン | 内容 |
|---|---|
| 🔊 | システム音声(Mac から出ている音)のオン / オフ |
| 🎤 | マイクのオン / オフ |
| ⏸ | 一時停止 / 再開 |
| ■ | 録画を停止 |

- システム音声とマイクを両方オンにすると、両方の音が 1 本の動画に入ります
- 音声の設定は次回の録画にも引き継がれます

### 録画を止める

次のどれかで止められます。

- 操作バーの ■ を押す
- もう一度 `⌥⇧⌘2` を押す
- メニューバーのアイコン(録画中は赤い ● と経過時間)をクリックする

### 録画したあと

録画した動画が画面の最前面に表示され、その場で再生できます。

| 操作 | 内容 |
|---|---|
| `⌘S` | MP4 で保存 |
| `⌘C` | 動画ファイルをコピー(Finder や Slack などに貼り付けられます) |
| `Esc` | 閉じる(保存していない場合は確認があります) |

## メニューバー

メニューバーのアイコンをクリックすると、次の操作ができます。

- 範囲をキャプチャ
- 画面を録画
- すべてのキャプチャを閉じる
- 設定…
- SnipReel を終了

## 設定

メニューバーのアイコン →「設定…」で、キャプチャと録画のショートカットを変更できます。ボタンをクリックしてから、新しいキーの組み合わせを押してください。

## 言語

日本語と英語に対応しています。macOS の言語設定に合わせて切り替わります。

SnipReel だけ言語を変えたい場合は、システム設定 →「一般」→「言語と地域」→「アプリケーション」で SnipReel を追加し、言語を選んでください。
